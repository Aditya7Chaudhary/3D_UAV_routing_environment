# Data assets

- `img/` — 2D occupancy images used by mode `1` of `read_grid_map`.
- `pcd/` — example point clouds for mode `4`.
- `pc1/` — preview images + STL meshes of classic indoor maps (bags omitted).
- `clear_pos/` — CSV start/goal clear zones for the structure generator.
- `semantics/` — example semantic obstacle lists (from upstream `vicon_env`).
- `dataset/` — sample generated PCD from the original package.
